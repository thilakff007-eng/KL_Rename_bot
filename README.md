# Rename Bot 🥀

An advanced and yet powerful Telegram Rename Bot that can rename and change thumbnail of your files.
This bot supports both 2GB and 4GB files, custom caption, custom prefix/suffix, custom metadata, and custom startup picture.

## Required Configs

* `BOT_TOKEN`  - Get Bot Token From @BotFather
* `API_ID` - From my.telegram.org
* `API_HASH` - From my.telegram.org
* `ADMIN` - Admin user IDs separated by space
* `DB_URL`  - Mongo Database URL
* `DB_NAME`  - Your Database Name
* `FORCE_SUB` - Your Force Sub Channel Username without @
* `LOG_CHANNEL` - Bot Logs Sending Channel
* `STRING_SESSION` - Your Tg Premium Account String Session Required for 4GB files.

## Features

* Renames very fast.
* Permanent Thumbnail support.
* Force join for the user.
* Supports Broadcasts.
* Custom File Name Support (Prefix & Suffix).
* Set custom caption.
* Has a custom Start-up pic.
* Force subscribe available.
* Supports unlimited renaming at a time.
* Custom Metadata Support.
* Admin Commands.
* Premium subscription and trial.
* Handle ban/unban members using command.
